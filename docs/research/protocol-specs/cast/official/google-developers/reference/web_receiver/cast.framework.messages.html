Namespace: messages Stay organized with collections Save and categorize content based on your preferences.

Page Summary

  • The cast.framework.messages namespace contains classes, enumerations, and properties for managing media playback and status on a Cast web receiver.

  • This namespace includes classes for metadata, tracks, breaks, media status, request/response data, and other related information.

  • Enumerations are defined to represent various states, types, and commands, including media types, player states, and messaging actions.

  • Both outgoing and incoming message types are outlined, covering requests such as load, pause, seek, and queue management, as well as responses like session state.

  • Static properties within the namespace provide direct access to common enumeration values.
